# Layout selection guide

Select a composition from the information the page must communicate. These are
patterns, not mandatory templates; combine them only when the reading order
stays obvious.

## Contents

- Narrative pages
- Evidence pages
- Relationship pages
- Selection rules

## Narrative pages

| Pattern | Best used for | Required material |
| --- | --- | --- |
| Cover | Name the deck and establish tone | literal title, optional subtitle/date/author |
| Section marker | Signal a real topic change | section name and one short framing line |
| Closing decision | End with a choice, commitment, or next action | conclusion plus owner/date when known |
| Statement page | Let one defensible idea dominate | one claim and optional proof/source |
| Quote | Present attributed language | exact quote, speaker, context/source |

## Evidence pages

| Pattern | Best used for | Required material |
| --- | --- | --- |
| KPI row | Compare two to four headline measures | value, unit, label, period/source |
| Chart focus | Explain a quantitative pattern | chart-ready data and one interpretation |
| Table | Support precise lookup or comparison | real rows, columns, units, notes |
| Image with annotation | Inspect a product, place, screenshot, or artifact | legible image plus concise labels |
| Evidence stack | Combine a claim with two or three supporting facts | claim, evidence, provenance |

## Relationship pages

| Pattern | Best used for | Required material |
| --- | --- | --- |
| Side-by-side comparison | Contrast two comparable options or states | shared dimensions and balanced evidence |
| Sequence | Show ordered work or time | named steps, direction, start/end |
| System map | Show actors or components and their links | nodes, relationship types, boundaries |
| Hierarchy | Show levels, ownership, or decomposition | parent-child structure |
| Matrix | Position items on two meaningful dimensions | axis definitions and item values |
| Timeline | Connect dated events or milestones | dates/periods and event descriptions |
| Before/after | Show a controlled change | equivalent views or measures on both sides |
| Portfolio grid | Scan repeated independent items | consistent fields for each item |

## Selection rules

1. Start with the page's reasoning shape: claim, comparison, sequence, hierarchy,
   system, quantity, or inspection.
2. Count real content before selecting slots. Never invent an item to fill the
   final card or column.
3. Preserve comparability. If two sides use different measures, use separate
   evidence blocks instead of a false comparison.
4. Prefer a direct chart or table when the numbers matter. Decorative diagrams
   should not replace data.
5. Give dense pages more space, not smaller type. Split only when the audience
   benefits from a second decision or explanatory beat.
6. Use full-bleed imagery only when the audience needs to inspect the actual
   subject. Atmospheric stock imagery is not evidence.
7. Vary the deck rhythm while keeping typography and navigation stable.

## Fill check

At 1920×1080, inspect the lower third of each page. Large unused space is valid
only when it supports emphasis. If it looks accidental, rebalance the existing
regions, enlarge the primary evidence, or choose a layout that matches the
available content. Do not add filler copy or decoration simply to occupy space.
